## 🎨 Color Reference

### Light Mode Palette
```css
/* Backgrounds */
bg-gray-50      /* Main background */
bg-white        /* Cards, buttons */
bg-gray-900     /* Code blocks */

/* Text */
text-gray-900   /* Primary text */
text-gray-600   /* Secondary text */
text-gray-300   /* Muted text (on dark) */

/* Accents */
bg-blue-600     /* Primary buttons */
bg-blue-700     /* Button hover */
text-blue-600   /* Links, accents */
border-blue-500 /* Hover borders */

/* Borders */
border-gray-200 /* Light borders */
border-gray-300 /* Medium borders */
border-gray-700 /* Dark borders (code) */

/* Shadows */
shadow-sm       /* Subtle */
shadow-md       /* Medium */
shadow-lg       /* Large */
shadow-xl       /* Extra large */
```
