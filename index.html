Build Electron Desktop Apps

A reactive framework for building fast, native desktop applications

Write Electron desktop apps using vanilla TypeScript with reactive signals, compiled templates, and zero virtual DOM overhead. Combines the simplicity of Vue-like single-file components with Solid.js-style fine-grained reactivity.

Why Rebuilder?

⚡

Lightning Fast

Fine-grained reactive system with signals means only what changed gets updated. No virtual DOM diffing overhead.

🖥️

Electron Native

Built specifically for Electron desktop apps. Main process, preload scripts, and IPC communication all included.

📦

Vanilla TypeScript

No JSX, no babel, no complex tooling. Just clean TypeScript with full type safety and intellisense support.

🎨

SFC Components

Write Vue-like single-file components with frontmatter, script, template, and style sections in .rebuilder files.

⚙️

Compiled Templates

Templates compile to optimized JavaScript at build time. Zero runtime template parsing overhead.

🎯

Developer-Friendly CLI

Scaffold projects, generate routes, and manage your app structure with powerful CLI commands.

See It In Action

📄 counter.ts 
import { r, createSignal } from '@rebuilder/system';

export default function CounterPage() {
  const [count, setCount] = createSignal(0);

  return r.div(
    { className: 'p-6' },

    r.h1(
      { className: 'text-4xl font-bold' },
      `Count: ${count()}`
    ),

    r.button(
      {
        onClick: () => setCount(c => c + 1),
        className: 'px-4 py-2 bg-blue-500'
      },
      'Increment'
    )
  );
}

Get Started in Minutes

1

Install Rebuilder

Create a new Electron desktop app with one command

npm install -g rebuilder-framework-cli
2

Create Your Project

Initialize a new project with the CLI

rebuilder init my-app
3

Start Building

Start the development server and see your app in action

cd my-app && npm install && npm run dev
4

Generate Routes

Add new pages to your app instantly

rebuilder create-router dashboard

Extend & Customize

🔌

Use Any Library

Rebuilder works seamlessly with any npm package. Install and use React, Vue, Svelte, Tailwind, or any Electron-compatible library directly in your components.

npm install three.js

npm install @tailwindcss/forms

npm install electron-is-dev

⚙️

Custom Generators

Create your own Electron build plugins and generators. Build specialized tooling for your team's needs - from custom installers to domain-specific app templates.

rebuilder-electron-build-plugin

rebuilder-react-template

rebuilder-installer-wix

📦

Plugin System

Extend Rebuilder's CLI with custom commands and hooks. Create workflow automations, custom builders, or integrate with your existing development pipeline.

rebuilder add:plugin

rebuilder run:hook

rebuilder config:set
